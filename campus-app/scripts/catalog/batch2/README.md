# Batch 2: review-only catalog import

Owner-approved UTF-8 inputs: 5 universities, 8 faculties, 17 bachelor courses,
and 5 logo research rows. The corrected full courses CSV is used. Logo metadata
is never imported. No image files are downloaded or referenced by the SQL.

From `campus-app`:

```sh
node scripts/catalog/build-batch1-sql.js scripts/catalog/batch2
node scripts/test-catalog.js
```

The existing generator now accepts a batch directory. Its default and the
legacy `node scripts/catalog/build-import-sql.js --batch1` command still produce
the original Batch 1 SQL, including its approved AzTU ID check. Tests freeze
the original Batch 1 SHA-256 and compare regenerated bytes.

Batch 2 generation is offline. It validates the approved exact names, CSV
relationships, counts, sources, bachelor level, verification, and blank teacher
fields. Exact faculty and source-aware course duplicates are removed. Rejections
include file and physical line number and prevent writing output.

The generated SQL is not executed by any script. Before the owner runs it,
all five university names must exist exactly once. The transaction precheck
raises an exception for missing/duplicate universities or ambiguous faculty
names. It does not create universities and uses exact names, not fixed IDs.
The TAU `Faculty not specified` row is inserted like every other faculty.

Faculty and course counts printed by the generator are candidates **if absent**,
not guaranteed new rows. Existing rows are never changed. Teachers, rooms, and
schedules are not set. SQL contains no student, enrollment, sample, or logo data.
Source verification flags describe the supplied owner-approved research.

The public onboarding GET inspected on 2026-10-25 showed one AMU and one ADMİU,
both with only `Faculty not specified`; BSU, TAU, and ATMU were absent. No SQL
was run to add them. The generated precheck will therefore stop until the owner
has resolved those prerequisites.

Read-only overlap inspection on 2026-10-25 scanned all 95 live course rows in
Supabase Table Editor, without SQL execution. AMU's existing course is
`Azərbaycan dilində işgüzar və akademik kommunikasiya`. ADMİU's existing courses
are `Rəsm`, `Rəngkarlıq`, and `Kompozisiyanın əsasları`. They are under each
university's `Faculty not specified` faculty. None is an exact or close name
match to Batch 2 courses, and neither existing faculty matches the new named
faculties. The other three universities are absent and have no associated
faculty or course rows. No rows were merged, removed, or edited.
